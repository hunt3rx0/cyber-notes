2. Enumeration

Nmap

# Full TCP scan
nmap -sC -sV -p- -T4 -oA nmap/full 10.10.10.XX

# UDP top ports
nmap -sU --top-ports 100 10.10.10.XX

Interesting ports:

  • 22/tcp – SSH
  • 80/tcp – HTTP
  • 445/tcp – SMB

Web Enumeration

gobuster dir -u http://10.10.10.XX -w /usr/share/wordlists/dirb/common.txt -x php,txt,html
