// COMMANDS

Working commands

TRIAGERECON

First pass on any unknown binary.

file ./sample
checksec --file=./sample 2>/dev/null || echo PE/other
strings -n 8 ./sample | head -100
strings -el ./sample | head -40
floss ./sample 2>/dev/null | less
STATIC

Locate main, interesting strings, crypto, and IO.

r2 -A ./sample
# aaa ; afl ; izz ; / flag
# Ghidra: import → analyze → search strings → xrefs
DYNAMIC

Run under debugger with safe args / fake inputs.

gdb -q ./sample
# pwndbg: checksec, vmmap, tele $rsp
break main
run < input.txt
strace -f -e open,read,write,connect ./sample
PATCH

NOP checks, force branches, dump decrypted buffers.

# r2: wx 90 @ addr   or   wa jmp 0x401234 @ addr
# Ghidra: Patch Instruction → export program
# re-test patched binary
// TTPS

Technique usage

STRING → XREFSTATIC
// WHEN

Flag format or API names appear in strings.

// CHAIN
  1. Locate string in Ghidra/r2.
  2. Xrefs to code that uses it.
  3. Trace args into crypto/compare functions.
gotcha: Compiler may split strings or build them on stack — search for fragments.
ANTI-DEBUGDYNAMIC
// WHEN

Sample exits early under debugger or VM.

// CHAIN
  1. Identify IsDebuggerPresent / ptrace / timing checks.
  2. Patch jump or return value.
  3. Continue analysis on patched binary.
gotcha: Multiple layered checks are common — re-run after each patch.
PACKER UNPACKTRIAGE
// WHEN

High entropy, few imports, weird entry.

// CHAIN
  1. Detect packer (DIE).
  2. Debug to OEP; dump memory.
  3. Fix IAT and analyze dump statically.
gotcha: Modern packers virtualize code — dump alone may not be enough.
CRYPTO ROUTINESTATIC
// WHEN

Custom encoding before network or file write.

// CHAIN
  1. Find constants (S-boxes, IVs, magic).
  2. Identify algorithm or reimplement in Python.
  3. Decrypt offline samples/traffic.
gotcha: Confirm endianness and key schedule before writing a decryptor.
PROTOCOL REDYNAMIC
// WHEN

Client talks to custom TCP/UDP service.

// CHAIN
  1. strace/Wireshark the conversation.
  2. Map message structures in RE tool.
  3. Rewrite client with pwntools/scapy.
gotcha: Length fields and checksums break naive replay — parse fully.
LICENSE / CRACKMEPATCH
// WHEN

Serial check or trial nag.

// CHAIN
  1. Find comparison after input transform.
  2. Patch JE/JNE or force success path.
  3. Document key algorithm if required by challenge.
gotcha: Some crackmes verify integrity of the binary — patch checks too.
