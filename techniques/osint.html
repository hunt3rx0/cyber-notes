Working commands

DOMAINRECON

Expand a company/root domain.

whois target.com
dig ANY target.com +noall +answer
curl -s 'https://crt.sh/?q=%25.target.com&output=json' | jq -r '.[].name_value' | sort -u
subfinder -d target.com -silent
SOCIAL

Pivot from a known alias.

sherlock username
curl -s https://api.github.com/users/username/repos | jq '.[].html_url'
IMAGE

Photo with no obvious caption.

exiftool photo.jpg
# reverse search: Google / Yandex / Lens
strings photo.jpg | head
RECON

Find exposed files and login panels.

# site:target.com filetype:pdf
# site:target.com inurl:admin
# site:target.com "index of"
# site:target.com ext:env OR ext:sql

SUBDOMAIN PIVOTDOMAIN
// WHEN

Need hidden CTF scoreboard or admin host.

// CHAIN
  1. CT logs + passive enum.
  2. Resolve and httpx title/status.
  3. Check takeover on NXDOMAIN CNAMEs.
gotcha: Wildcard DNS creates false positives — filter by content hash.
PEOPLE SEARCHPEOPLE
// WHEN

Challenge gives a name or email.

// CHAIN
  1. Search public pastes/profiles in scope only.
  2. Username variants on major platforms.
  3. Correlate employer + location hints.
gotcha: Stay in scope — real doxxing is out of bounds for legitimate CTFs.
GEO FROM PHOTOGEO
// WHEN

Landscape or street scene.

// CHAIN
  1. Read EXIF GPS if present.
  2. Reverse image search landmarks.
  3. UI language, power plugs, vegetation as clues.
gotcha: Stripped EXIF is normal — visual OSINT matters more.
INFRA BANNERINFRA
// WHEN

IP or CIDR in challenge text.

// CHAIN
  1. Shodan/Censys host query.
  2. Match TLS cert CN to domains.
  3. Note outdated software for next stage.
gotcha: CDN shared IPs mislead — prefer cert and host header evidence.

  1. Wayback calendar snapshots.

  3. Recover robots.txt and sitemaps.
