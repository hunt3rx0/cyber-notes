// COMMANDS

Working commands

PCAPRECON

First look at a capture.

capinfos capture.pcap
tshark -r capture.pcap -q -z endpoints,ip
tshark -r capture.pcap -Y 'http.request' -T fields -e http.host -e http.request.uri
tshark -r capture.pcap -Y 'dns' -T fields -e dns.qry.name | sort -u
PCAP

Recover files from HTTP/SMB streams.

tshark -r capture.pcap --export-objects http,/tmp/http_obj
tcpflow -r capture.pcap -o /tmp/flows
MEMORY

Identify OS profile and list processes.

vol -f mem.dmp windows.info
vol -f mem.dmp windows.pslist
vol -f mem.dmp windows.netscan
vol -f mem.dmp windows.filescan | grep -i flag
DISK

Mount or carve an evidence image.

file evidence.img
mmls evidence.img
fls -r -p evidence.img
binwalk -e firmware.bin
foremost -i blob.bin -o /tmp/carved
// TTPS

Technique usage

HTTP EXFILPCAP
// WHEN

Suspicious POSTs or encoded query params.

// CHAIN
  1. Filter http.request.method == POST.
  2. Follow TCP/HTTP stream.
  3. Decode base64/URL/hex payloads offline.
gotcha: Chunked or multi-request exfil needs reassembly across packets.
MEMORY CREDENTIALSMEMORY
// WHEN

Need passwords, keys, or injected code.

// CHAIN
  1. pslist / pstree for odd processes.
  2. malfind + dump sections.
  3. hashdump / cmdline artifacts.
gotcha: Wrong profile/symbol table yields empty plugins — confirm windows.info first.
STEGO IMAGESTEGO
// WHEN

Challenge gives a PNG/JPEG with nothing obvious.

// CHAIN
  1. exiftool + strings + zsteg.
  2. Check LSB / bit planes in stegsolve.
  3. Try steghide with wordlist if passphrase required.
gotcha: Trailing ZIP after IEND is common — run binwalk.
DELETED FILESDISK
// WHEN

File was deleted but still recoverable.

// CHAIN
  1. fls/icat or Autopsy deleted view.
  2. Search unallocated with bulk_extractor.
  3. Carve by header/footer if FS metadata gone.
gotcha: SSD TRIM may zero unallocated — carving can fail on modern disks.
BROWSER ARTIFACTSDISK
// WHEN

User activity on a workstation image.

// CHAIN
  1. Locate History/Login Data/Cookies DB.
  2. sqlite3 queries on Chromium DBs.
  3. Correlate with downloads and typed URLs.
gotcha: Profiles may be multiple — check every user path.
TIMELINETIMELINE
// WHEN

Need sequence of attacker actions.

// CHAIN
  1. Build plaso timeline from disk.
  2. Filter by path/keyword around incident window.
  3. Cross-check with EVTX and prefetch.
gotcha: Timezone skew between artifacts is a frequent CTF trick.
