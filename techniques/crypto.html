AES

Guess mode from behavior.

# ECB: repeated plaintext blocks → repeated ciphertext blocks
# CBC: needs IV; bit-flip on Ci affects Pi+1
# CTR/GCM: nonce reuse is fatal
openssl enc -aes-128-ecb -d -K KEYHEX -in c.bin -out p.bin

Technique usage

RSA WIENERRSA
// WHEN

Large e or unusually short private exponent.

// CHAIN
  1. Check e and n bit sizes.
  2. Run Wiener / Boneh-Durfee style attacks.
  3. Decrypt with recovered d.
gotcha: Not every large-e key is Wiener-vulnerable — verify bounds.
COMMON MODULUSRSA
// WHEN

Same n, different e, related messages.

// CHAIN
  1. Collect ciphertexts under e1,e2.
  2. Apply common-modulus attack.
  3. Recover plaintext without factors.
gotcha: Messages must be identical (or related by known polynomial).
ECB CUT-AND-PASTEAES
// WHEN

ECB mode cookie or token.

// CHAIN
  1. Align blocks by padding input length.
  2. Swap ciphertext blocks to escalate role.
  3. Verify server parses spliced token.
gotcha: Needs block boundary control — prefix length matters.
CBC BIT FLIPAES
// WHEN

CBC ciphertext; flip a flag bit.

// CHAIN
  1. Flip bits in Ci to alter Pi+1.
  2. Account for prior block corruption.
  3. Automate if padding oracle returns errors.
gotcha: Without an oracle, flips are blind — know exact plaintext structure.
PADDING ORACLEORACLE
// WHEN

Server distinguishes padding errors.

// CHAIN
  1. Confirm oracle (timing or error text).
  2. Decrypt byte-by-byte from the end.
  3. Forge valid ciphertexts for arbitrary plaintext.
gotcha: Constant-time apps may still leak via different exception paths.
HASH LENGTH EXTHASH
// WHEN

Secret-prefix MAC = H(secret||message).

// CHAIN
  1. Identify hash (MD5/SHA1).
  2. Use hashpump / custom extension.
  3. Append admin data with valid tag.
gotcha: Does not work for HMAC — only naive prefix MACs.
