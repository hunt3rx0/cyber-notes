Linux Privilege Escalation

Privesc Linux

Quick Checklist

  • sudo -l
  • SUID binaries
  • Capabilities
  • Cron jobs
  • Writable files / PATH hijack
  • Kernel exploits
  • Credentials in files

Useful Commands

# Check sudo
sudo -l

# Find SUID
find / -perm -4000 2>/dev/null

# Capabilities
getcap -r / 2>/dev/null

# Cron jobs
ls -la /etc/cron*

# Interesting files
grep -R "password" /home 2>/dev/null
cat /etc/passwd
cat /etc/shadow   # if readable

Common Techniques

Sudo misconfiguration

If you can run certain binaries as root with sudo, check GTFOBins.

SUID binaries

Look for unusual SUID binaries and check GTFOBins for privilege escalation methods.

⚠️ Note Always try the easiest methods first (sudo -l, SUID, cron) before kernel exploits.
