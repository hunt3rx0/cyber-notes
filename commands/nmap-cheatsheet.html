Nmap Cheatsheet

Nmap Recon

Basic Scans

# Ping scan (discover live hosts)
nmap -sn 10.10.10.0/24

# Quick scan
nmap -T4 -F 10.10.10.10

# Full TCP + scripts + versions
nmap -sC -sV -p- -T4 -oA fullscan 10.10.10.10

Useful Flags

  • -sC – default scripts
  • -sV – version detection
  • -p- – all ports
  • -T4 – faster timing
  • -oA name – output all formats
  • -Pn – skip host discovery
  • -A – aggressive scan

UDP & Specific Ports

# Top UDP ports
nmap -sU --top-ports 100 10.10.10.10

# Specific ports
nmap -p 22,80,443,445,3389 10.10.10.10

# Vulnerability scripts
nmap --script vuln 10.10.10.10
💡 Tip Always start with a quick scan, then dig deeper on interesting ports. Save everything with -oA.
