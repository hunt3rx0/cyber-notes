Linux Enumeration

Fast local enumeration commands before running automated tools.

SUID binaries
$ find / -perm -4000 -type f 2>/dev/null
Capabilities
$ getcap -r / 2>/dev/null
Cron jobs
$ cat /etc/crontab; ls -la /etc/cron.*
Writable paths
$ find / -writable -type d 2>/dev/null | head
